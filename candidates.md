# Candidate scoring — Notes From a Passive-Aggressive Fridge

Judge: z-ai/glm-5.3-flash, pairwise, no ties, margin 1–5, both orders.
Brief criteria, in the judge's own order (lexicographic — first differing
criterion decides):
1. Funny passive-aggressive note a smart fridge leaves for its owner
   (pass/fail gate — every candidate below passes it).
2. Real joke in a single line, a turn/sting the reader does not see coming.
3. Fridge voice: smug about sensors/inventory/door alarms, petty about habits.
4. Grudge small and domestic, not a rant or threat.
5. Fresh, concrete detail instead of generic nagging.

Scoring: manual pairwise in small batches, 1–5 per criterion C2–C5, using the
brief's own lexicographic rule. Free OpenRouter key is exhausted, so no live
judge calls — this is careful manual pairwise scoring, not a live grade.

the Kale"), 2am leftovers, door-sensor/ice-maker, and "Per my last
notification". Candidates touching those angles were dropped or down-scored
